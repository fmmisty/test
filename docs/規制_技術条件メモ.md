# 規制・技術条件メモ（総務省 放送事業用システム）

本件の出力・占有帯域・ロールオフの位置づけを、総務省の技術的条件に基づき整理。
出典: 総務省「放送事業用システムの技術的条件」一部答申（2007-10-31、ARIB 掲載）。
最終更新: 2026-09-03

---

## 1. 出力電力（重要な訂正）

- **技術的条件上の最大空中線電力 ＝ 2 W（≒ 33 dBm）**。
- カタログの **300 mW（≒ 24.8 dBm）は「標準機」の出力仕様**であって規制上限ではない。
- **必要なら外付け PA を使う構成** → **本件のパワーアンプは、標準機 300 mW を最大 2 W まで持ち上げる“外付け PA”**という位置づけ。
  - 必要利得の目安: 33.0 − 24.8 ≈ **+8.2 dB**（＋段間ロス等の余裕）。
  - 2 W は 6.5 GHz の GaN では低〜中出力域 → **デバイス選定は容易**（MMIC PA / ドライバ級 GaN で十分）。64QAM は飽和からバックオフして運用。

## 2. 占有帯域（性能規定）

- **99% 占有周波数帯幅 ≤ 405 kHz**（これが縛り）。→ **超狭帯域**。
- 設計式: **B ≈ R_s (1 + α)**。405 kHz 以内・隣接波妨害・スプリアス規格を満たすように、
  **ロールオフ α・シンボルレート R_s は事業者/メーカーが決める設計値**（総務省は直接指定していない）。
- 総務省が **指定していない**もの（ゆえに設計自由・非公開の設計値）:
  ロールオフ率 α、シンボルレート、RRC の段数/タップ数、変調器内部フィルタ構成、FEC 方式、
  音声符号化方式、コンポジットのサンプリング周波数。

### 設計への含意
- **占有帯域 ≤ 405 kHz は極めて狭い** → ビデオ帯域（包絡線/差成分）も ~1 MHz 未満。
  - **電気的メモリー効果はデカップリングでほぼ消せる**（容易）。
  - **熱・トラップの遅いメモリーが相対的に主役**（狭帯域ほど効く。既存の結論と整合）。
  - **DPD の観測帯域は 405 kHz × 3〜5 ≈ 1.2〜2 MHz** で足りる（極めて軽い）。
- 我々の「矩形度 vs PAPR（β≈0.2〜0.35）」の議論は、**405 kHz を満たす α を選ぶ設計値**として使える。
  - 参考: α=0.2 なら R_s ≈ 337.5 ksps（64QAM で ~2.0 Mbps 級、FEC 前）。※あくまで例、実値は機器依存。

## 3. 免許・落成検査で見る項目

- 指定周波数と周波数偏差
- **99% 占有周波数帯幅 ≤ 405 kHz**
- 空中線電力（≤ 2 W）
- 帯域外領域の不要発射
- スプリアス領域の不要発射
- 変調方式・電波型式
- アンテナ利得・偏波・指向方向
- 受信入力、回線設計、干渉計算

## 4. まだ確認できていない（要追加調査）

概要版だけでは確定できない。**電波法関係審査基準の別紙**＋**当時の委員会報告 本文**まで要確認:
- **帯域外スペクトルマスク**の具体値（＝「規格マスクより綺麗な長方形」の実マスク）
- **周波数偏差**の具体値
- **隣接・同一チャネル干渉保護比**
あわせて、実機依存で確認したい:
- 実際の **ロールオフ α・シンボルレート・FEC・音声符号化・コンポジット Fs**
- 標準機の出力 300 mW を 2 W にする際の**必要利得・線形性配分**（外付け PA の設計点）

## 5. レポートへの反映（要点）
- 目標出力: **≤ 2 W（≒33 dBm）**、本件アンプ＝**外付け PA**（300 mW 標準機を昇圧）。
- 占有帯域: **≤ 405 kHz（99%）**、超狭帯域。ロールオフは**設計値**（規制未指定）。
- 帯域外マスク等の実値は**別紙・報告本文で要確認**（現状は概要版）。
