# 総まとめ — 6.5 GHz(M バンド) GaN HEMT アンプ 64QAM 歪み補償プロジェクト

本プロジェクトでこれまで調査・検証・試作した内容の総まとめ（インデックス兼エグゼクティブサマリ）。
最終更新: 2026-09-03

---

## 0. エグゼクティブサマリ（結論だけ）

**目的＝GaAs 廃番(EOL)対応の GaN 置換。** 原設計(2020, FM 福井 MN-band D-STL)の 1 W PA は GaAs デバイスで、その GaAs が入手不可に。これを**現行 C 帯 GaN で作り直し、同じ 1 W 仕様（+30 dBm・マスク −37/−48 dBc・占有 ≤405 kHz・64QAM/α0.2）を再現**する（増力ではない）。実装現実を踏まえた現実解は：

> **C 帯 GaN MMIC PA（石は MMIC で整合・多段を IC 内解決）＋ シングルエンド級AB を深バックオフ＋強力放熱 ＋ DPD（MP 7次/深さ5 → 不足なら GMP）。効率が要件なら ET（狭帯域で有利、Doherty は 6.5GHz の 1/4波長問題で不利）。**

- **メモリー効果は狭帯域でも消えない**：電気的メモリーは楽になるが、**熱・トラップの遅いメモリーが主役**。対策＝バイアスのビデオ帯域インピーダンス低減＋放熱＋電流コラプス小のデバイス選定＋（必要なら）長時定数補償。
- メーカー実機（三菱電機特機システムの DPD 開発）で**同一の静的特性でもバイアス回路違いで DPD 効果が 10dB 差**＝我々の「メモリー効果が鍵」を実証。

## 1. 確定した要件

| 項目 | 内容 |
|---|---|
| 周波数 | **M バンド 6.570–6.870 GHz**（総務省 放送事業用区分）。**音声**伝送（N バンド＝映像は対象外） |
| 運用 | 単一キャリア・同時運用なし・**周波数アジャイル**（バンド内を可変） |
| 変調（実機） | **64QAM・R_s=374.4 ksps・α=0.2**（送受均等）。実機 TX 6716.625 MHz。PAPR≈6〜6.5dB |
| 占有帯域 | **99% 占有帯 ≤ 405 kHz**。実マスク **−37 dBc@±250kHz / −48 dBc@±750kHz** |
| 出力 | **従来実機 1 W（+30 dBm）**。規制上限 2 W（増力なら外付け PA） |
| 合否 | EVM ≦ 8%、ACLR ≧ ~30 dBc（PAPR ゆえ 飽和−7〜9dB バックオフ） |
| デバイス | GaN HEMT。2W は低出力ゆえ選定容易。実装は **MMIC PA 推奨**（6.5GHz の整合・1/4波長問題を回避） |
| 線形化 | **DPD 主軸**（MP→GMP→必要なら NN） |

## 2. 主要な技術的結論（根拠つき）

1. **歪みの要因**：AM/AM・AM/PM＋メモリー効果（電気的／熱／トラップ）。→ `6p5GHz…設計調査レポート.md` §4
2. **メモリー効果は 2 階層**：①デバイス物理（電流コラプス/ゲート・ドレインラグ/DC-RF 分散）②システム挙動（DPD が補正）。→ §7.5, `メモリー効果の抑制・除去.md`
3. **狭帯域（音声）でも熱・トラップの遅いメモリーは残る/むしろ効く**（裏取り済：Katz, Boumaiza）。→ `裏取り_検証メモ.md`
4. **DPD にメモリ項は必須**：メモリレス DPD では EVM 7.5% 止まり、MP 7次/深さ5 で 2.0% まで改善（シミュレーション実証）。→ `DPD_メモリー効果_シミュレーション結果.md`
5. **Doherty は 6.5GHz で不利**（1/4波長 3.6–5.3mm、モジュールで非効率）→ 集中定数/MMIC のみ。効率手段は **ET**（狭帯域で容易）。→ §5, `裏取り_検証メモ.md`
6. **入手 GaN はレーダー志向**（飽和・大電流・大発熱）→ 深バックオフ＋放熱前提。→ §3
7. **スペクトルは「規格マスクより綺麗な長方形」**に：送信フィルタで形、DPD＋バックオフで肩を規格以下。**β≈0.2〜0.35** がスイートスポット（β↓で矩形化も PAPR 増）。→ `スペクトル整形_矩形度vsPAPR.md`
8. **メーカー実機の裏付け**：MESW 技報（400MHz/256QAM）で DPD＋ILA＋Simulink→FPGA、ACP −57.1dB 達成。§4.6.2 がメモリー効果の実測証拠。→ `MESW技報_解析と裏取り.md`

## 3. 推奨アーキテクチャ

```
[BB: 64QAM] → [DPD (MP7次/深さ5→GMP)] → [DAC] → [アップコンバータ] → [C帯 GaN MMIC PA] → 6.5GHz出力
     ↑ 係数適応(ILA)                                                   │(カプラ)
     └──────── [ADC] ← [ダウンコン(観測受信器)] ←────────────────────┘
外部で作り込む: バイアスのビデオ帯域インピーダンス低減 / 放熱 / (効率要件時)ET
```

- 段1 素の線形性：級AB＋ロードプル/高調波終端＋バイアス回路（電気的メモリー抑制）
- 段2 効率：まずバックオフ主体、要件次第で ET（Doherty は不利）
- 段3 線形化：DPD（MP→GMP→NN）、周波数アジャイルは周波数別係数 or 都度再適応
- 6.5GHz ゆえ**アップコン必須**（400MHz のダイレクト RF は使えない）

## 4. DPD の実装方針

- **モデル**：まず MP（7次・メモリー深さ5）→ ACLR 不足時のみ GMP 交差項。→ 必要なら NN（Flux/OpenDPD）
- **学習**：間接学習(ILA)＋最小二乗/リッジ。温度・電源変動に背景適応
- **数式・必読3本**：Morgan GMP(2006)/Boumaiza 熱(2003)/Ku&Kenney(2003)。→ 設計レポート §6.0
- **実機化**：MATLAB/Simulink or **Julia**（`θ=Φ\y`）でモデル同定 → FPGA（JESD204B, 量子化）
- **データ→モデル**：`sim/dpd_model_from_data.jl`（Julia）。NN 雛形：`sim/nn_dpd_demo.py`（実行済, EVM7.6%）/`sim/nn_dpd_flux.jl`

---

## 5. デバイス（石）の方針

- **MMIC PA 推奨**（整合・多段・ドハティを IC 内解決、50Ω 入出力、6–8GHz 内部整合で 6.87GHz も入れやすい）
- **非住友候補**：Wolfspeed/MACOM（CGHV1F006S 等）、Qorvo、ADI、MACOM の C 帯 GaN MMIC PA。住友は SGK5867（〜6.75GHz）
- ただし **バイアス給電・放熱・DPD は自前**（MMIC でも残る）。**電流コラプス小/線形グレード**品を優先。→ `非住友_GaN_HEMTデバイス調査.md`

1. **帯域外スペクトルマスク・周波数偏差・干渉保護比**の具体値（→ 電波法関係審査基準の別紙＋委員会報告本文。概要版には無い）
2. **実機のロールオフ α・シンボルレート・FEC・音声符号化**（405kHz を満たす設計値）
3. **外付け PA の設計点**（300mW→2W の必要利得・線形性配分・バックオフ）
4. **運用上端**：M バンド全域(〜6.87GHz)か 6.75GHz 以下か／各社データシート（P1dB・パルス I-V・電流コラプス・線形性）
5. **効率要件**（ET を入れるか、バックオフ主体でよいか）

> 規制の詳細は `規制_技術条件メモ.md`（総務省 2007 答申ベース）を参照。出力 ≤2W・占有帯 ≤405kHz は確定。

## 9. 一言サマリ
**「石は C 帯 GaN MMIC で楽に、効率は割り切って深バックオフ＋放熱、歪みは DPD（MP→GMP→NN）で。狭帯域でも効く熱・トラップのメモリーを、バイアス回路と熱設計と DPD で叩く」** — これが本プロジェクトの現実解。残りは音声チャネル諸元と目標出力の確定待ち。
