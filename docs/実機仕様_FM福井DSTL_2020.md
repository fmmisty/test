## 2. 64QAM 変調部（実機パラメータ）★重要

| 項目 | 値 |
|---|---|
| 変調方式 | **64QAM** |
| **シンボルレート** | **374.4 ksps** |
| **ロールオフ率 α** | **0.2（送受均等配分＝RRC 各 0.2）** |
| 伝送モード | 音声リニア PCM／コンポジットリニア PCM |
| サンプリング | 48 kHz（音声）／120 kHz（コンポジット） |

**導出**: B99 ≈ R_s(1+α) の 99% 占有 ≈ 374.4k × 1.08 ≈ **405 kHz** ✓（α=0.2 と整合）。
64QAM/RRC α=0.2 の **PAPR ≈ 6〜6.5 dB**（0.01% CCDF）。

## 6. 本プロジェクトへの反映（確定値）

| これまでの仮定 | 実機の確定値 |
|---|---|
| 出力 ≤2 W（規制上限） | **従来実機は 1 W(+30 dBm)**。2 W は規制上限で、増力するなら外付け PA |
| PAPR 5〜7 dB（仮） | **α=0.2 → PAPR ≈ 6〜6.5 dB** |
| 占有帯 ≤405 kHz | **確定**（R_s=374.4 ksps, α=0.2） |
| マスクは例示 | **実マスク: −37 dBc@±250 kHz / −48 dBc@±750 kHz** |
| 周波数 6.5 GHz 帯 | **6716.625 MHz（MAF-33）** |

**電力バジェット（実機 1 W 基準）**:
- 平均 +30 dBm、PAPR ~6.5 dB → **尖頭 ~+36.5 dBm（≈4.5 W）**。
- 線形（64QAM, マスク −37/−48 dBc）を満たすには尖頭が Psat より数 dB 下 → **デバイス Psat ~+40 dBm(10W) 級**が安全（DPD で 6〜8 W 級も可）。
- ⇒ Qorvo QPA1013D(10W) / Wolfspeed CMPA601C025F(25W) は **1 W 設計でも 2 W 増力でも適合**。

**要確認（新規プロジェクトの狙い）**:
- 新アンプの目標は **①従来 1 W に DPD を足して線形性/マスク余裕を稼ぐ**のか、
  **②2 W へ増力（外付け PA）**するのか。→ これで Psat とバックオフ配分が決まる。
- 従来機がこのマスク（−37/−48 dBc）を **DPD 無しで達成**していたのか（＝現状の線形化方式）も確認したい。
