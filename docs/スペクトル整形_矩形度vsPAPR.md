# スペクトル矩形度 vs PAPR トレードオフ（送信 RRC ロールオフ掃引）

「規格マスクより綺麗な長方形」を送信フィルタで作るときの基本トレードオフを数値化。
コード: [`sim/spectrum_shaping.py`](../sim/spectrum_shaping.py) / 図: `docs/figures/spectrum_shaping.png`

## 条件
単一キャリア 64QAM（狭帯域・音声リンク相当）、ルートレイズドコサイン(RRC) 整形、ロールオフ β を掃引。
指標＝PAPR[dB]（0.01% CCDF 近似）と シェイプファクタ SF＝B(-30dB)/B(-3dB)（1 に近いほど矩形）。

## 結果

| β（ロールオフ） | PAPR [dB] | SF（矩形度, 小さいほど矩形） | 傾向 |
|---|---|---|---|
| 0.10 | **7.39** | 1.80 | 最も急峻な矩形・PAPR 高・**サイドローブ増** |
| 0.22 | 6.79 | **1.79** | **バランス良（推奨域）** |
| 0.35 | 6.25 | 1.94 | やや丸い・PAPR 低 |
| 0.50 | 6.02 | 2.15 | 丸い・PAPR 最低 |

## 読み方（トレードオフ）
- **β を小さくするほど帯域端が急峻＝矩形に近づく**が、**PAPR が増える**（7.4 → 6.0 dB）。PAPR が増えると、同じ EVM/ACLR を保つのに**より大きいバックオフ（＝効率低下）**か**より強い DPD**が要る。
- **β を小さくしすぎると RRC のサイドローブが増え**、かえって遠方のマスク余裕を食う（図左：β=0.1 の裾のリップル）。→ **極端に急峻化しない**のがコツ。
- 実務の**スイートスポットは β ≈ 0.2〜0.35**。矩形度・PAPR・サイドローブのバランスが良い。

## 本件（音声・狭帯域）への指針
1. **送信フィルタで矩形の形を作る**（β≈0.2〜0.25 目安）。狭帯域なので急峻化しやすい。
2. **DPD＋バックオフで肩（再成長）を規格マスク以下に**押し下げる（別図参照）。
3. β をむやみに下げず、**PAPR とバックオフ（効率）・DPD 複雑度のバランス**で決める。

> 音声チャネルの**実際のシンボルレート・占有帯域・マスク規格値**が分かれば、`sim/spectrum_shaping.py` の `PARAMS` を差し替えるだけで、横軸を実 Hz にして**本物のマスク余裕**を評価できます。
